# Dune 验证

根据用户要求和实际改动，取得与待交付行为相匹配的验证证据。

- 在仓库根目录执行命令。输入是改动范围、待验证行为和指定环境；有 Git 时结合 diff 确认范围，没有 Git 时使用本次修改清单，不自行初始化仓库。
- 从 [开发流程](../../../docs/workflow.md#按改动选择检查) 选择覆盖相关行为的检查，先读对应测试确认覆盖内容。只有涉及外部环境时再读该文档的外部验收部分。
- 失败时区分产品回归、依赖缺失与环境限制。在授权范围内修复并重跑受影响检查；同一阻塞没有新证据时不反复运行。一个外部验证受阻不妨碍完成其他本地验证。
- 真实 Agent/远端测试只在任务包含对应验收且环境已配置时启用。检查进程环境是否已有 `DUNE_REAL_AGENT` 或 `DUNE_REMOTE_CONFIG`，避免普通回归意外调用外部资源；不要输出配置中的凭据。
- 结果列出实际命令、通过/失败/跳过、证明的行为及剩余缺口。`TestRealAgentACP` 只证明初始化握手；mock 测试、交叉编译、历史记录分别只能证明其覆盖内容，不能据此声称真实编码任务或平台运行已验收。
